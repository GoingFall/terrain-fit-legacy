Perf: a full fitting iteration is now ~43 s instead of minutes

Generation was pathological because the density function had no wrappers: the game evaluated the
whole 128 KB noise graph per block. Vanilla wraps its own terrain in exactly these nodes:

  interpolated( blend_density( add( cache_2d(height), -y ) ) )

  * cache_2d    -- the height term is 2D, so it is computed once per column
  * interpolated -- sample the 4x4x4 cell grid and interpolate

Measured with the headless server (256-block area, 64 chunks):

  export      ~2 s
  server boot 16.0 s   (JVM + registry, unavoidable per launch)
  generation  ~21 s    (~0.3 s/chunk;  earlier: >7 min, never finished)
  shutdown     1.1 s
  measure     ~4 s
  total       43 s

Other fixes:
- the probe blocked on readline when the server went quiet, so its stop condition never ran
- the run directory is reused, so libraries are not re-unpacked every time
- validate mode returns right after "Done (" instead of waiting for spawn chunks: 19 s
- fit_loop runs a single server call (a bad pack fails at boot) and defaults to a 128-block area
