Runtime parameters: a fitting iteration no longer needs a rebuild

The mod now reads config/terrainfit.json at startup (FitParams), and tools/fit_model.py can write
and read the same file, so the Python preview and the in-game generator stay on one parameter set.

- FitParams: 26 parameters, loaded from the config dir, written back with defaults if absent
- HeightmapChunkGenerator reads sea level and snow line from the same file
- tools/fit_loop_mod.py: write config -> boot Forge server -> forceload a window -> measure ->
  distance, all in one command, with --set and --search

Verified: changing reliefMacro from 180 to 300 with no rebuild moved the generated terrain from
relief 112 to 161 (and the log shows "[terrain-fit] loaded params from ...").

First real search (reliefMacro 250..500, four points, 5m23s total): best distance 0.636 against the
reference region, with slope p50/p90 exactly 0.71/1.58 at every point -- the remaining gap is in
relief (204 vs 238) and snow cover (37.6% vs 63.9%), both directly searchable now.
