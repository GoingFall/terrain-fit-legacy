Offline harness: validate and generate with a headless vanilla server

Every recent failure was a JSON schema guess validated by launching the client. This replaces that
loop: tools/server_probe.py runs a real 1.20.1 server with the pack installed, reports the exact
codec error (the same DataFixerUpper messages the client shows), and in generate mode forceloads a
fixed 512-block area so terrain_metrics.py can measure what the game actually produced.

- accepts the pack, optionally overrides minecraft:overworld with our noise settings so the
  generated overworld can be measured
- stops the server itself; skips truncated region files left behind by an interrupt
- first real run: PACK PARSED, 6 region files generated, measured relief 221, flat 13.3%,
  snow 8.4% (target 238 / 13.5% / 63.9%)
